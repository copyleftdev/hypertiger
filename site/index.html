  1. 20.72 s. An order leaves with a deadline.

    Buy 1.953 ETH. expiresAfter tells the exchange to refuse it after 22.75 s, and that is what makes the question answerable at all.

  2. 22.22 s. No usable reply. The track forks.

    1.5 seconds have passed. It may have landed or it may not, and nothing on this side of the network can tell which. Dashed means in doubt.

  3. 22.75 s. The deadline passes, and the doubt stays.

    The bar ends the world where it never landed. The engine still counts all 1.953 in full and does not resend. A resend here could put a second order on the book.

  4. 23.82 s. A second order forks the same way.

    Same state, same rule. This one is 1.749 ETH, reduce-only, and it is counted too.

  5. 24.77 s. The first order turns up.

    A fill of 0.371 ETH proves it landed. The world where it did not collapses, and the track goes solid. Nothing had to be guessed.

  6. 25.50 s. The second never does.

    Past its deadline and the 1 second margin, the model exchange says it never saw that client id. That is a proof, so its exposure is released. A stub barred at the deadline is what never landing looks like.

  7. Twenty-nine times in this run.

    19 were proven never landed and 10 were found to have landed. The bound held at every 10 ms step of the run's 120 simulated seconds, from the moment the engine recovered.

The bound holds in every world.

No Default, on purpose.

The configuration has no defaults, because each of these fields changes what can happen to money. That is the whole attitude.

If you run bots

A crash is an ordinary start. The engine waits out whatever a previous life could have left in flight, then adopts what the exchange says is open. There is no local state to corrupt, because the exchange is the log. The settle margin is yours to measure before going live.

If you read Rust

The kernel is no_std, with no alloc and no floats. It takes bytes and gives bytes, depends only on k256 and sha3, and keeps its assertions on. It follows TigerBeetle's TigerStyle, and a seed that fails replays exactly.

// No Default on purpose: each of these changes
// what can happen to money.
let config = EngineConfig {
    network: Network::Testnet,
    user: wallet.address(),
    vault: None,
    tick_ms: 100,
    order_ttl_ms: 5_000,
    settle_margin_ms: 2_000, // Measure this.
    request_timeout_ms: 3_000,
    queue_ms_max: 2_000,
    status_poll_ms: 1_000,
    reconcile_ms: 30_000,
    fills_wait_ms: 5_000,
    weight_per_minute: 800,
    weight_burst: 300,
    weight_cancel_reserve: 50,
    fast_cancel: true,
};
